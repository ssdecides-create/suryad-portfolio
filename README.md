# Surya D — Product Design Portfolio

Static site. No build step.

- Entry: `index.html` (the homepage itself, no redirect)
- Live: https://suryadesignportfolio.netlify.app

## Deploy
**Vercel:** Add New → Project → import this repo → Framework preset: *Other* → Deploy.
**Netlify:** Add new site → Import from Git → pick this repo → leave build command empty, publish directory `/`.
**GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → `main` / root.
